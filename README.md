# FF14 潜水艇材料计算器

一个**离线单文件**的部队潜水艇配装计算器：选好四个部件，直接算出这套潜艇要用的全部材料、获取方式和用量。

可以直接双击网页使用。

---

## 这是什么

计算制作一套/多套潜水艇配件所需的材料：

- 选了 `4254全改`，立刻告诉你这套要哪些材料、各多少
- 每种材料标出**获得方式**：NPC售价、军票换、自己采、潜艇带、用风茄/薰衣草换，还是自己做
- 已经有的材料填个数字，只算**还缺多少**
- 一键导出 CSV，拿去 Excel 里标记

## 怎么用

1. 下载 `dist/潜水艇材料计算器.html`
2. 双击，用浏览器打开
3. 左侧选套装或手动选四个部件
4. 看材料，填已有，导出

**在线版**：<https://bannkann.github.io/FF14-submarine-calculator/> —— 不用下载，点开就能用。

> 没有做手机端适配，电脑也可能不适配...

### 界面里的四栏

| 栏位 | 含义 |
|---|---|
| **配件队列** | 你选的四个部件 |
| **计算队列** | 这些部件里需要自己做的半成品 |
| **直接素材** | 做半成品要的材料 |
| **基础素材** | 最基础的原料——要采集、要买的就是这些 |

### 几个小操作

- **填已有**：每行左边的输入框，填你有多少个，只算差额
- **管够**：填 `-1`，或在 0 上点一下向下的箭头，显示成 √
- **整列管够**：点列表头的勾选框，适合「只差一两样」的情况
- **一次做几套**：套装右边的 ×N
- **导出**：右上角，CSV 可以直接用 Excel / WPS 打开

## 支持的东西

- 全部 40 个部件（5 个级别 × 普通/改级 × 4 个位置）
- 常用套装一键填充（`1111` / `1121` / `3124` / `4254全改` / `3124全改`）
- 材料获取方式：NPC 售卖（含价格）、军票兑换（含总需军票）、采集、限时采集、潜水艇带取、风茄/薰衣草兑换、制作
- 改级部件的骨架会自动按「用普通部件 1:1 兑换」展开
